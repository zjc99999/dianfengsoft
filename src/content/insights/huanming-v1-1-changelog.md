## 这次更新了什么

- **按内容理解的命名方式**：对文件名本身没有语义的截图、扫描件，可选择读取内容摘要来理解并命名；这一页需要用户主动启用，并明确告知数据去向。
- **批量任务进度**：大批量改名时显示预计剩余时间，避免"不知道跑没跑完"的焦虑。
- **更可靠的恢复日志**：改名记录写得更完整，一键恢复的成功率更高。

## 为什么这样排优先级

三项更新都围绕"让用户敢用"：能力边界讲清楚、过程看得见、改错了能退回。功能做得多不算数，敢让人批量执行才算数。

## 边界

按内容理解依赖用户自己配置的 API 或官方免费通道，识别效果因内容而异；我们不承诺具体准确率，只承诺数据去向透明。
