## 纯函数内核

BMI、基础代谢（Mifflin-St Jeor）、每日总消耗（TDEE 五档系数）、目标热量全部收敛为纯函数，集中在 `utils/calculator.js`。单测 **81 项全部通过**（原 AC1–AC5 的 27 项无回归 + v0.5 新增 54 项），而且 `node utils/calculator.test.js` **无需小程序环境即可运行**——计算正确性不依赖任何平台。

## 源码 0 处业务网络请求

全库扫描 `wx.request / uploadFile / downloadFile / fetch / http(s)://` 命中 0（唯一 URL 是 sitemap.json 的注释链接）；真机 Network 面板 0 条业务请求。没有账号、没有云同步、没有支付。这不是「我们承诺不传」，而是可以从代码层面核验的事实。

## 数据只进本机

数据只进 4 个存储 key：`hc_profile_v1` / `hc_weight_log_v1` / `hc_food_log_v1` / `hc_water_v1`；清空档案时 4 组一并二次确认清除。

## 代码级验收全绿

23 个 JS `node --check` 通过、21 份 JSON 合法、`tools/verify_v05_port.py` 全通过（14 页 4 件套 / tabBar / 组件引用 / WXML / 无网络请求 / 名称口径）。

## 取舍

对一款健康工具来说，「算得准」和「不上传」同等重要。把计算做成可独立测试的纯函数，把隐私做成可静态核验的事实——**能自证的承诺，才是承诺。**
