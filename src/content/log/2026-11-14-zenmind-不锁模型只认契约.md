## 不锁 DeepSeek

项目明确「能接任何模型，不锁 DeepSeek」——业务层只认一份 JSON 契约（judge / gloss / reading / release / action / follow / mood），换模型只改环境变量。这让模型选择变成运营参数，而不是架构决策。

## 14 模型表

内置 14 模型表：deepseek-chat 是中文古典语感最好的默认主力，glm-5.3-flash 为当前主力（约 6 秒、¥0.0018/次），glm-4-flash 作免费备胎；gpt-4o-mini / claude-3-5-sonnet 列为境外模型。全站单次开示成本约 ¥0.005，一万次不到 50 元。

## 适配层的两条路

按厂商分两条路：OpenAI 兼容 9 家、Anthropic 走原生 `/messages`；JSON 约束分 schema / object / prompt 三档，`cleanJSON` 兜六种脏格式，校验失败把错误原话回传模型（被记为「修 JSON 最有效一招」）；主模型全挂则降级本地内容，永不返回错误。

## 踩坑与三级解析

豆包 model 必须填 Endpoint ID（`ep-xxx`）否则 404；改 `LLM_MODEL` 不生效，于是做三级解析（精确→别名→厂商族推断），让 `glm-5.4-flash` 这类新名字不改代码即可用；GLM-5.x 必须带 `reasoning_effort:'low'`——实测不带时 1598 推理 token / 39 秒 / content 空，带时仅 5 token / 6.3 秒即正常。

## 真正的约束是数据出境

用户写「我很焦虑 / 想辞职 / 活不下去」≈《个保法》第 28 条敏感个人信息，不适用 <10 万人豁免。因此实时开示只用境内模型（DeepSeek + GLM4Flash），Claude 仅用于离线内容生产。**模型能力不是上限，合规边界才是。**
