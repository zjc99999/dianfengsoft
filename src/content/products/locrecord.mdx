## 这是什么

静记 LocRecord 是一个纯本地的会议 / 访谈录音整理工具。导入录音（WAV / MP3 / M4A / FLAC / OGG / MP4）后，全部处理在本机完成——**录音不出这台电脑**，产出逐字稿、说话人分段，以及结构化的「要点 / 决议 / 待办」三段纪要，并可导出为 Markdown、Word、Obsidian 笔记或剪贴板。

它面向的是对隐私敏感、又确实需要会议纪要的场景：内部访谈、客户沟通、咨询记录——这些录音不适合上传到任何云ASR服务。静记用本地模型（SenseVoice / Whisper ONNX）做转写，网络默认关闭，没有账号，也没有遥测。

## 设计上的取舍

- **本地优先，隐私可证**：不只是「声明不上传」，而是给出双证据——静态扫描代码无 HTTP 调用，动态 79 次网络采样中 TCP / UDP 连接恒为 0；连授权也走离线 ed25519 验签 + 机器码绑定，不依赖在线账号。
- **轻量桌面架构**：Tauri 2 + Rust + Vue 3，安装包约 12.4 MiB，模型与安装包分离；用 sherpa-onnx（SenseVoice int8）做本地 ASV，Symphonia + ffmpeg 兜底解码，rusqlite FTS5 trigram 做中文全文检索。
- **结构化而非只有逐字稿**：VAD 分段 → 本地 ASR → 可选说话人分离（pyannote + 3D-Speaker）→ 三段纪要抽取 → 逐句校对 + 术语表，形成「能直接用」的纪要而不是一堆文字。
- **诚实的能力边界**：说话人分离是可选能力，中文 CER 按保守口径如实标注（约 20.94%），试用以次数计而非假免费。

## 证据与现状
