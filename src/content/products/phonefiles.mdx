## 这是什么

PhoneFiles 是一个只读、可核对、离线优先的 Windows 桌面工具：通过 MTP 直连安卓手机，扫描中文语义目录（相机、截图、下载、录音，以及微信 / QQ / 钉钉的私有数据目录），把需要的文件一键复制到电脑，并生成一份带 SHA-256 校验值的 UTF-8 清单（`清单.csv`）。

它解决的是一个很具体、也很普遍的焦虑：**手机空间要清理，但不敢删——怕没备份全、怕删错**。PhoneFiles 的答案是「只读归档 + 可核对清单」：搬过去的文件逐条可校验，确认无误后再决定手机端怎么处理。工具本身永不删除、不修改手机上的任何数据。

## 设计上的取舍

- **只读优先，绝不改动手机数据**：全程只做「读 + 复制」，每一处 App 私有目录都是逐目录实测可读才收录（"可见 ≠ 可读"），不能读的明确标注，不假装支持。
- **无路径抽象，传输层可插拔**：内部不用字符串拼接路径，只使用 MTP 的不透明对象 ID（opaqueId），把「语义目录识别」和「文件传输」解耦——将来换传输方式，上层规则不用重写。
- **语义规则引擎 + 置信度**：按操作系统家族、ROM 家族、SDK 版本范围、App 包名匹配目录，置信度加权；规则来自脱敏观测，经「观测 → 规则 → 双人 review → 灰度 → 稳定」的流程沉淀，且经过严格的隐私脱敏校验器。
- **离线优先、零遥测**：核心流程不发任何网络请求；可选的观测数据也在本地脱敏后才能进入社区规则库。

## 证据与现状

在真机 Redmi 10X Pro（MIUI 13 / Android 12）上完成 1211 个文件、945 MB 的完整归档，并验证增量跳过 1211 个文件；自检 18/18、校验器 5/5、构建 0 warning。当前为 MVP v0.6（开源发布）。**明确边界**：面向 Windows + 安卓（MTP），暂不支持 iOS；定位为早期版本，仍在持续打磨中。
