## 这是什么

照水（ZenMind）是一个 AI 自修 × 修身养性的交互平台。用户通过一场五步问心仪式——择石、净手、默念、化墨、照见——写下内心的困扰，由境内大模型生成一段有文学质感的「开示」，渲染成一张带时间刻度与永久编号的心镜卡，可保存、可分享。产品以今日签、情绪之树、我的签谱形成长期积累，以会员的「追问一次」和月度「心相长卷」完成变现。

**它是什么、不是什么，边界很清楚**：照水是自修 / 认知反思工具，不是心理服务、情感陪伴、医疗诊断，也不提供任何预测——这不是免责声明，而是产品设计和合规红线。

## 设计上的取舍

- **仪式感不是花架子**：五步流程把「输入一句话」变成两分钟的专注动作；化墨是用 canvas 抹墨完成的「仪式性卸载」，只卸载、不产出结论——一旦产出结论就变成占卜，性质就变了。
- **AI 工程化，且坚持境内处理**：`core/llm.js` 是 14 个模型的适配层（DeepSeek / GLM / Qwen / 豆包 / Kimi / OpenAI / Anthropic / 本地模型等），OpenAI 兼容与 Anthropic 原生双分支、JSON 契约校验、失败重试、主备链自动切换、全挂降级本地签文池；用户输入坚持由境内模型处理，满足数据出境合规。
- **出图不用文生图**：所有卡片走 HTML 截图（puppeteer-core + 本机 Chrome），文字锐利、改版不用重训模型；心镜卡带戌时 / 农历 / 月相等真实时间刻度和双编号。
- **合规即产品能力**：关键词前置拦截 + 危机热线一键拨打，且不渲染卡片；语气守门员（11 类禁用句式）；付费明确「不自动扣款」；把合规做进产品，而不是贴个声明。
- **增长与商业化一体化**：免费层带水印卡分享回流，付费层（¥9.9 首月 / ¥19.9 月 / ¥99 年 / ¥199 深度解惑）做变现；18 类埋点 + 来源归因 + 周数据看板自动给出「扩量 / 换素材 / 砍」结论。
